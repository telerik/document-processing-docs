# Release History and Changelog

The release history and changelog provide a comprehensive list of new features, bug fixes, improvements, and breaking changes introduced across all versions of the Telerik Document Processing libraries.

Starting with Q2 2025, the [Telerik Document Processing]({%slug introduction%}) libraries are available as a separate distribution in the **Downloads** section of your [Telerik account](https://www.telerik.com/account/). 

## Official Changelog and Release Notes

To inspect the full changelog for each release:

* Visit the official [Telerik Document Processing Release History and Changelog](https://www.telerik.com/support/whats-new/telerik-document-processing/release-history) page to track releases in detail and review the introduced improvements.
* Browse the version-specific articles in this [Release Notes]({%slug dpl-release-history%}) section for highlighted product updates.
